# 📊 Antenatal Care (ANC) Dashboard

This project presents an interactive Excel dashboard developed using HMIS data to monitor Antenatal Care (ANC) services and maternal health indicators. The dashboard provides a comprehensive view of registrations, high-risk pregnancies, testing coverage, and complications across different regions.

## 📌 Objective
I conducted a detailed analysis on the Annual Antenatal Care (ANC) service delivery, which utilized data collected from the Health Management Information System (HMIS). The aim of the analysis was to evaluate key maternal health parameters in Primary Health Centers (PHCs) in Udupi district and develop an interactive dashboard for efficient monitoring and decision-making purposes. In this context, the analysis included ANC registration patterns in different Taluks, monitoring maternal health conditions such as Gestational Diabetes Mellitus (GDM), hypertension, and eclampsia, as well as anaemia and haemoglobin levels, immunization and testing, and high-risk pregnancy (HRP).
